# 前端 UI 布局与组件设计

## 整体布局

当前前端是一个“左文档、右流程/驾驶舱”的工作台，而不是单纯的编辑器 + 聊天框。

```text
┌──────────────────────────────────────────────────────────────────────────┐
│ Toolbar                                                                 │
│ [上传 docx] [新建文档] [下载] [招标分析] [建议模式/直接编辑]              │
├───────────────────────────────────────┬──────────────────────────────────┤
│ Editor Panel                          │ Chat / Cockpit Panel             │
│                                       │                                  │
│ 文档标题 + 状态摘要                    │ 头部：当前文档 + tab 切换         │
│ [采纳全部修订] [拒绝全部修订]          │ [文档 Agent] [招标驾驶舱]         │
│                                       │                                  │
│ SuperDoc toolbar / 只读提示            │ Agent tab:                       │
│ SuperDoc 文档区域                      │ - 消息流                         │
│                                       │ - tool call / tool result 卡片   │
│                                       │ - Plan 卡片                      │
│                                       │ - 招标分析步骤流                 │
│                                       │ - 输入框 + 图片附件 + Plan Mode  │
│                                       │                                  │
│                                       │ Cockpit tab:                     │
│                                       │ - 概况、时间线、预算、清单       │
│                                       │ - 评分矩阵、风险、开放问题       │
│                                       │ - 证据抽屉与原文联动             │
├───────────────────────────────────────┴──────────────────────────────────┤
│ Status Bar: 文档状态 | 当前模式 | 当前文档                               │
└──────────────────────────────────────────────────────────────────────────┘
```

## 顶层组件树

```text
<App>
  <TamboAppProvider>
    <Toolbar />
    <MainLayout
      left={<EditorPanel />}
      right={<ChatPanel />}
    />
    <StatusBar />
  </TamboAppProvider>
</App>
```

## 主要组件

### `Toolbar`

当前工具栏包含：

- 上传 `.docx`
- 新建文档
- 下载当前文档
- 启动“招标分析”
- 切换建议模式 / 直接编辑

交互规则：

- 点击“招标分析”会把左侧编辑器切到只读查看模式
- 打开新文档时会清空聊天消息和分析状态
- 分析只读模式下，不允许切换回可编辑模式

### `MainLayout`

- 桌面端左右分栏，默认左侧约 72%
- 中间有可拖拽分隔条
- 支持键盘调整宽度
- 窄屏下自动改为上下堆叠

### `EditorPanel`

左侧编辑器区当前包含三层状态：

- 空状态：提示先上传或新建文档
- 普通编辑状态：显示 SuperDoc toolbar 和文档内容
- 招标分析只读状态：隐藏编辑工具栏，展示“证据联动定位”提示

额外交互：

- 建议模式下显示“采纳全部修订 / 拒绝全部修订”
- 顶部副标题会显示模式、载入状态、定位反馈
- 收到证据定位请求后，会尝试在文档里搜索、滚动、选区高亮

### `ChatPanel`

右侧有两个 tab：

- `文档 Agent`
- `招标驾驶舱`

`文档 Agent` tab 包含：

- starter prompts
- 消息列表
- tool call / tool result 展示
- Plan 卡片
- 招标分析运行步骤流
- 输入区

`招标驾驶舱` tab 包含：

- `TenderDashboard`
- 固定业务面板，不是自由聊天式 UI

### `StatusBar`

底部状态栏当前统一展示：

- 文档连接/保存状态：`idle / loading / ready / saving / error`
- 当前模式：建议模式 / 直接编辑 / 查看模式
- 当前文档名称
- AI 是否正在处理

## Agent 面板交互

### 消息流

- 用户消息支持文字和图片缩略图
- AI 普通回复以轻量文本显示
- 工具调用单独渲染为状态卡片
- Plan Mode 下会插入单独的计划卡片，而不是混在普通文本里

### Tool 卡片

当前会显示：

- 工具名与执行状态
- 摘要说明
- 修订数量
- 是否需要刷新编辑器
- 可恢复错误提示
- 模糊匹配候选位置
- 插图锚点候选位置

### Plan 卡片

支持三种状态：

- `awaiting_decision`
- `collecting_feedback`
- `executing`

用户可以：

- 直接确认执行
- 拒绝并补充约束，再让 Agent 重新生成计划

### 输入区

输入区当前支持：

- Enter 发送，Shift + Enter 换行
- 上传图片
- 直接粘贴截图
- 删除未发送附件
- 切换 Plan Mode

招标分析只读模式下：

- 禁止上传图片
- 禁止开启 Plan Mode
- placeholder 改成“解释条款 / 总结要点 / 点击证据回看原文”

## 招标驾驶舱设计

驾驶舱是固定板块式布局，当前包含：

- `TenderOverviewBoard`
  - 项目概况
  - 商务条款
  - 联系人
- `TenderTimelineBoard`
  - 时间线节点
  - 冲突与过滤
  - 节点确认
  - deadline todo 生成
- `LotAndBudgetTable`
- `TenderChecklistBoard`
  - 资格条件
  - 投标文件要求
  - 技术范围
  - 合规标记
- `EvaluationMatrix`
- `RiskRegisterBoard`
- `OpenQuestionsPanel`
- `EvidenceDrawer`

## 驾驶舱交互重点

### 字段修订

- 大部分面板支持直接编辑提取结果
- 保存后通过 PATCH API 更新 snapshot
- 状态通常被标记为 `user_edited`

### 证据抽屉

- 点击“查看证据”打开右侧抽屉
- 抽屉显示摘录、章节路径、表格定位、置信度
- 点击某条证据会触发左侧原文定位

### 原文定位

证据定位时会尽量使用：

1. `source_excerpt`
2. `matched_text`
3. `source_section_path`

定位成功后，左侧会滚动到目标位置并高亮当前段落。

### Tambo 状态保持

若配置 `VITE_TAMBO_API_KEY`，部分驾驶舱交互状态可跨会话保留，例如：

- 评分矩阵密度模式
- 时间线视图模式
- 风险筛选
- 面板展开状态
