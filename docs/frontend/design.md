# 前端 UI 布局与组件设计

## 整体布局

类似 VSCode + Claude Code 的双栏布局：

```
┌─────────────────────────────────────────────────────────────────┐
│  Toolbar (顶部工具栏)                                            │
│  [上传文档] [新建文档] [下载] [编辑模式 ▾] [建议/直接 切换]          │
├────────────────────────────────────┬────────────────────────────┤
│                                    │                            │
│         文档编辑区域                 │       Chat 面板             │
│         (SuperDoc Editor)          │                            │
│                                    │  ┌──────────────────────┐  │
│   ┌─────────────────────────────┐  │  │ AI: 你好，需要帮你     │  │
│   │                             │  │  │ 修改什么内容？          │  │
│   │    .docx 文档渲染            │  │  └──────────────────────┘  │
│   │    (所见即所得编辑)           │  │                            │
│   │                             │  │  ┌──────────────────────┐  │
│   │                             │  │  │ 用户: 把第二段改成      │  │
│   │                             │  │  │ 更正式的语气            │  │
│   │                             │  │  └──────────────────────┘  │
│   │                             │  │                            │
│   │                             │  │  ┌──────────────────────┐  │
│   │                             │  │  │ AI: [正在编辑...]      │  │
│   │                             │  │  │ ✓ 已修改第二段，使用了   │  │
│   │                             │  │  │ 3 处 tracked changes   │  │
│   │                             │  │  └──────────────────────┘  │
│   │                             │  │                            │
│   └─────────────────────────────┘  │  ┌──────────────────────┐  │
│                                    │  │ [输入消息...]     [发送] │  │
│                                    │  └──────────────────────┘  │
├────────────────────────────────────┴────────────────────────────┤
│  Status Bar (底部状态栏): 连接状态 | AI 状态 | 文档信息            │
└─────────────────────────────────────────────────────────────────┘
```

## React 组件树

```
<App>
  <Toolbar />                        # 顶部操作栏
  <MainLayout>                       # 可拖拽分栏
    <EditorPanel>
      <SuperDocEditor />             # superdoc 编辑器实例
    </EditorPanel>
    <ChatPanel>
      <MessageList>
        <MessageBubble />            # 单条消息（支持用户/AI/系统）
        <ToolCallIndicator />        # AI 工具调用状态显示
      </MessageList>
      <ChatInput />                  # 输入框 + 发送按钮
    </ChatPanel>
  </MainLayout>
  <StatusBar />                      # 底部状态栏
```

## 关键交互细节

### Chat 面板

- 消息流式显示（WebSocket 流式推送 AI 回复）
- AI 执行工具调用时，显示进度指示器（如"正在查找内容..."、"正在修改第 3 段..."）
- 聊天历史保持在当前会话内（MVP 不做持久化）

### 编辑器面板

- SuperDoc 编辑器渲染 .docx，用户也可以手动编辑
- AI 的 tracked changes 以高亮标记显示，用户可逐条接受/拒绝
- 分栏宽度可拖拽调整

### Toolbar

- 上传：选择本地 .docx 文件上传
- 新建：创建空白文档
- 下载：将当前文档导出为 .docx 下载
- 编辑模式切换：建议模式 / 直接生效模式
